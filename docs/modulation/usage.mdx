Modulation is designed to be highly customizable. Every module and its tweaks can be easily adjusted to fit your playstyle.

### Configuration
* **In-Game Menu**: Modulation uses **YACL** (Yet Another Config Lib), giving you an easy-to-use configuration menu right in game.
* **Config File**: You can also manually edit the config file. Modulation generates a `modulation.json` file inside your instance's config directory.

Almost every tweak can be disabled or fine-tuned, so feel free to experiment!
