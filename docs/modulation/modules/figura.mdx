This module significantly improves the Figura commands for managing player avatars.

**Features:**
* **Target Selectors**: Modifies the `/figura load` and `/figura clear` commands. Unlike base Figura, these commands support vanilla target selectors (like `@a` for all players, `@p` for nearest, etc.), allowing you to change skins for multiple people at once!
* **Skin Autofill**: Figura's load commands now provide smart tab-completion/autofill suggestions for skins located in your local avatars folder.
