This module contains tweaks for inventory and other in-game screens.

**Features:**
* **Ctrl+Click/Drag to Crafting Grid**: Hold Control while clicking or dragging items in your inventory to transfer them directly into the crafting grid.
* **Chat Message Duration**: Configure how long (in ticks) chat messages stay on screen before fading out.
* **Disable Creative Inventory**: Stops the game from showing the Creative menu and adds a Clear Inventory / Destroy Item button to the survival inventory screen when in Creative mode.
* **Clear Button Position**: Configure the X and Y position offsets of the inventory clear button relative to the inventory window.
* **Chat Markdown**: Adds bold (`**text**`), italic (`*text*`), strikethrough (`~~text~~`), and underline (`~text~`) formatting to chat messages.
* **Cursor Feedback**: Changes the mouse cursor shape when hovering buttons, sliders, text fields, scroll bars, disabled widgets, and clickable text links.
* **Slot Highlight Behind Item**: Draws most of the slot hover highlight underneath the item instead of on top of it, keeping the item readable. Backported from 1.21.2, and uses the vanilla `minecraft:container/slot_highlight_back` and `minecraft:container/slot_highlight_front` sprite paths, so resource packs made for 1.21.2+ should work without changes.
