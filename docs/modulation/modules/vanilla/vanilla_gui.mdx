This module contains tweaks for inventory and other in-game screens.

**Features:**
* **Ctrl+Click/Drag to Crafting Grid**: Hold Control while clicking or dragging items in your inventory to transfer them directly into the crafting grid.
* **Chat Message Duration**: Configure how long (in ticks) chat messages stay on screen before fading out.
* **Disable Creative Inventory**: Stops the game from showing the Creative menu.
