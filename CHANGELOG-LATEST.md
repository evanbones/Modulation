- Ported to 26.1, 26.2, and 26.3.

### Changed

- Some features are only available on 1.21.1. On 26.x:
    - The Bugfixes module only has Improved Fog. Use [Debugify](https://modrinth.com/mod/debugify) for general bugfixes.
    - Slot Highlight Behind Item, Extended Clouds, Cursor Feedback, and Ender Pearl Sound are removed, as vanilla
      already does these.
    - Leaf particles for the passable foliage module no longer need Vanilla Backport, as they use vanilla's own leaf
      particles.
    - Figura integration is not available (still 1.21.1-only).
- YACL is now an optional dependency.
